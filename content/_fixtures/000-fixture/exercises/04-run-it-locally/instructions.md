## The situation

Some exercises happen on your own computer instead of in the browser.
This one checks that your bug-hunt fix works in real Python too.

## Your task

1. Make a folder anywhere, with a file in it called `fix.py`.
2. Paste in your fixed `add_member` from the bug hunt.
3. Below it, add two calls that each start a new team, and print the results.
4. Open a terminal in that folder and run `python fix.py`.
5. Tick each item in the checklist when it's true.

## Example

```bash
$ python fix.py
['pikachu']
['eevee']
```
